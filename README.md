# Restaurant Ordering App

A React-based restaurant ordering application inspired by platforms like **Swiggy**.  
This project allows users to browse restaurants, view menus, add items to cart, and place orders.

The app is built using a **component-based React architecture** with **Redux for state management**.

## Project Status

This project is currently **under development**.

The application integrates with the **Swiggy API**, but because the API changes frequently, some features are not fully stable or working as expected yet. Continuous updates are required to keep the app compatible with the latest API structure.

## Features

- Browse restaurant listings
- View restaurant details and menus
- Add and remove items from cart
- Manage cart state with Redux
- Reusable component-based React structure
- Dynamic data fetching from Swiggy API
- Responsive UI design

## Tech Stack

- **React.js**
- **Redux**
- **JavaScript**
- **HTML5**
- **Tailwind css**
- **Swiggy API**

## Architecture

The project follows a **component-based structure** in React for better maintainability and reusability.

State management is handled using **Redux**, which helps manage:
- Cart data
- Restaurant/menu data
- Application state across components

## Challenges

One of the major challenges in this project is the **frequent change in the Swiggy API**.  
Because of these updates:
- Some endpoints stop working
- Response structures change
- Existing features may break unexpectedly

As a result, the app is not fully completed yet and requires ongoing fixes and updates.
